# painbot

Лента IT-болей → идеи → разбор в канал → вертикальный рилс. Бот сам собирает
жалобы разработчиков из Reddit, Hacker News и GitHub Issues, отсеивает шум,
превращает одобренное в статью с картинками и в озвученный ролик. Человек в этом
конвейере жмёт только ✅ или ❌.

## Запуск

```
pip install -r requirements.txt
```

Дальше `run.bat` (или `python -m app.bot.main`). Скрипт сам поднимет `.venv`,
поставит зависимости и запустит бота вместе с админкой.

Перед первым запуском скопируй `.env.example` в `.env` и заполни как минимум
`TG_TOKEN` и один ключ LLM. Всё остальное правится потом в админке — она пишет
в ту же базу и имеет приоритет над файлом.

Для рендера нужен `ffmpeg` (кладётся в `bin/ffmpeg.exe` рядом с проектом) и
браузер Playwright — `playwright install chromium`.

## Конвейер

1. **Сбор** — `app/collect/`. Reddit ходит через Arctic Shift, так что учётные
   данные Reddit не нужны; GitHub и HN — по своим API. Дедуп по нормализованному
   заголовку, чтобы одна и та же боль не приезжала трижды.
2. **Скрининг** — LLM отбрасывает не-IT и мусор до того, как боль попадёт в
   инбокс. Дешёвая модель, промпт в `app/llm/prompts/screen.md`.
3. **Аппрув** — ты листаешь инбокс в боте и одобряешь то, что стоит разбирать.
4. **Идеи** — из одобренной боли рождается несколько тем разбора
   (`prompts/ideate.md`).
5. **Разбор** — статья с блоками, к каждому блоку рендерится своя картинка:
   mermaid-диаграмма или HTML-мокап, снятые Playwright'ом
   (`app/media/render.py`).
6. **Рилс** — сценарий → озвучка → анимированные кадры → сборка. Кадры это
   HTML-шаблоны из `app/media/templates/anim/`, оживлённые GSAP; видео режется
   и склеивается ffmpeg'ом.

Каждый шаг доступен и отдельной кнопкой, и целиком одним прогоном — общий код
живёт в `app/jobs/steps.py`, а вызывающий решает, как масштабировать
прогресс-бар.

## Как это устроено

Один процесс на всё: бот, планировщик и админка. Долгие задачи не блокируют
Telegram — они уходят в очередь (`app/jobs/queue.py`), воркер тянет их по
одной и репортит прогресс обратно в сообщение.

Модели не захардкожены. Провайдер выбирается по тому, какой ключ заполнен:
kie → OpenRouter → Anthropic. Промпты лежат отдельными `.md` файлами и
перечитываются с диска, так что переписать тон разбора можно без перезапуска.

Озвучка по умолчанию — Edge TTS, бесплатно и без ключа. ElevenLabs включается
в админке, если нужен голос получше.

Готовые ролики и картинки уезжают в Cloudflare R2 под префиксом `painbot/` —
бакет общий с ugc-cg, префикс разделяет архивы.

```
painbot/
├── app/
│   ├── bot/       aiogram: хендлеры, клавиатуры, FSM
│   ├── admin/     локальная веб-админка на 127.0.0.1:8765
│   ├── collect/   источники болей + дедуп
│   ├── llm/       промпты и вызовы моделей
│   ├── jobs/      очередь, воркер, шаги конвейера, планировщик
│   ├── media/     рендер кадров, TTS, сборка видео, R2
│   └── db/        SQLite: схема и репозиторий
├── docs/
└── run.bat
```

## Админка

`/admin` в боте или <http://127.0.0.1:8765>. Слушает только локалхост. Оттуда
правятся ключи, модели, источники, расписание сбора, геометрия ролика и тексты
промптов.
